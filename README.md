# Curso de Claude Code - EDteam

Recursos del curso de [Claude Code](https://docs.anthropic.com/en/docs/claude-code) de [EDteam](https://ed.team).

## Estructura del Repositorio

### 01-todo-list

Aplicación de lista de tareas construida con vanilla JavaScript. Proyecto introductorio para demostrar las capacidades básicas de Claude Code.

**Tecnologías:** HTML, CSS, JavaScript
**Ejecutar:** `npm start` (sirve en puerto 5173)

### 02-todo-list-go

Aplicación de lista de tareas en Go con interfaz de línea de comandos. Incluye persistencia en JSON, estadísticas y sistema de backups.

**Tecnologías:** Go
**Ejecutar:** `go run main.go`

### 03-skills

Demostración de Skills de Claude Code. Contiene ejemplos de procesamiento de datos CSV y generación de reportes HTML.

### 04-mcp-connection

Ejemplo de configuración y uso de servidores MCP (Model Context Protocol) con Claude Code.

### test-marketplace

Proyecto de ejemplo para la creación de plugins de Claude Code. Incluye:

- Agents personalizados
- Slash commands
- Hooks
- Skills
- Configuración de MCP

## Requisitos

- [Node.js](https://nodejs.org/) (para proyectos JavaScript)
- [Go](https://golang.org/) (para proyectos Go)
- [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code)
